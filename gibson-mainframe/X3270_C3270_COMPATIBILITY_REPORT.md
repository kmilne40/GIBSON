# x3270/c3270 Compatibility Report

Implemented:

- Transfer-style option parser;
- typed Transfer-style command mapping;
- s3270 scripted command-mode validation material.

Not live-validated in this sandbox:

- x3270/c3270 native `Transfer()` structured-field protocol against real client binaries.

Compatibility is therefore described as staged and command-mode validated, not as a guaranteed full structured-field implementation.
