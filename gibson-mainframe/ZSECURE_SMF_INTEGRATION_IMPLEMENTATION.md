# zSecure SMF Integration

Extended zSecure command handling with SMF-oriented views:

- `ZSEC SMF`
- `ZSEC SMF80`
- `ZSEC PASSTICKET`
- `ZSEC CICS`
- `ZSEC DB2`
- `ZSEC NETWORK`
- `ZSEC USS`
- `ZSEC ICSF`
- `ZSEC TIMELINE <correlation-id>`

These views query the structured SMF writer and retain legacy zSecure findings behaviour.
