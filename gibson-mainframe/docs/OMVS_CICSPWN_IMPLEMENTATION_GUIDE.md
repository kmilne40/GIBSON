# OMVS CICSPWN Implementation Guide

`CICSPWN` and `cicspwn` provide a bounded CICS assessment simulator. It validates HOSTS.TXT scope, fingerprints the Gibson VTAM/CICS path, enumerates key transactions, shows CEMT/CEDA/CECI/CEDF protection state, records forensic correlation metadata and never submits JCL or runs a real shell.
