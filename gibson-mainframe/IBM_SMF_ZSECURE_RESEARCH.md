# IBM SMF and zSecure Research Notes

Design was based on public IBM documentation and mainframe practitioner references for SMF headers, SMF Type 30 job/session activity, SMF Type 80 RACF security processing, PassTicket Type 80 generate/evaluate semantics, CICS Type 110 monitoring/statistics, z/OS UNIX Type 92 file activity, Db2 100/101/102 records, Communications Server Type 119 records, z/OS Connect Type 123 request records, ICSF key-management evidence concepts, and zSecure-style SMF/RACF review workflows.

The delivered implementation is analytically faithful for training but intentionally does not claim binary compatibility with IBM SMF record layouts.
