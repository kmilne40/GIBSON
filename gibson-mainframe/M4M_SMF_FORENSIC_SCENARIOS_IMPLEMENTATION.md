# M4M SMF Forensic Scenarios

Added ten M4M/Navigator attack-layer scenario mappings covering:

- OSINT/mainframe footprinting
- phishing path to mainframe users
- adversary-in-the-middle against TN3270/FTP
- CICS to JES internal reader abuse
- writable APF-authorized library escalation
- RACF/Db2/dataset collection
- exfiltration of PII/card data
- offline RACF hash cracking
- JES/SDSF/SYSOUT footprint reduction
- dataset encryption impact scenario

Each scenario lists required SMF record types, zSecure views, forensic questions and investigation steps.
