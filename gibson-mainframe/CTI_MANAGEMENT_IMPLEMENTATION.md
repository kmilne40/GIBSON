# CTI Management Implementation

Gibson Sentry now has local management workflows for feeds, providers, API keys, threat actors, vulnerabilities and TTPs. Data is stored in Gibson datasets/JSON stores such as `FIBS.CTI.PROVIDERS`, `FIBS.CTI.APIKEYS`, `FIBS.CTI.ACTORS`, `FIBS.CTI.VULNS` and `FIBS.CTI.TTPS`. API keys are displayed only as redacted metadata.
